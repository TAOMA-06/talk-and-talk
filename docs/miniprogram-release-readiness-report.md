## 本机前后端联通结论

已验证的本机流程为：小程序 API 层可连接本机后端；后端使用独立 PostgreSQL 与 Redis 测试实例；从模拟微信登录、协议同意、订单创建/确认，到 Mock 支付、支付后聊天、退款与取消均可跑通。也就是说，**“电脑作为测试后端”的应用功能链路已经可以完整运行**。

该结论仅针对本机开发/测试环境：Mock 登录和 Mock 支付用于验证前后端业务契约，不能替代微信服务器实际调用、真实用户授权或真实扣款。

## 发布建议

当前状态适合进入“微信真实环境联调 / 体验版测试”阶段，不建议跳过上述阻塞项直接宣称商用发布完成。

建议按以下顺序完成最终放行：

1. 部署公开 HTTPS 后端，注入正式小程序和微信支付密钥，并运行部署预检。
2. 将后端域名、业务域名、下载域名和合法回调地址配置到微信公众平台。
3. 通过微信开发者工具和至少一台真机验证真实登录、拒绝授权、订单、真实支付/退款及消息同步。
4. 在部署机或 CI 完成容器启动、数据库迁移、健康检查、日志/指标和回滚演练。
5. 核对隐私保护指引、用户协议、内容审核和客服/投诉处理流程后提交微信审核。

完成以上五项并保留真实环境的验收记录后，结论即可从“有条件通过”升级为“可提交微信审核”；审核通过后才适合正式对外商用。
