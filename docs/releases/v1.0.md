# Talk&Talk v1.0 发布说明

日期：2026-09-04

## 正式版本范围

Talk&Talk v1.0 是微信小程序优先的线上文字陪伴版本。正式上传源为
`frontend/miniprogram`，不是历史截图评审工程。

- 31 个小程序页面、5 个底部入口与 18 个共享组件。
- 发现、陪伴广场、陪伴者资料、结构化服务与档期、预约、接单、支付页、订单消息、评价、售后、投诉与账号权利界面。
- 普通 active 账号可发布广场内容、创建预约、支付并在有效订单窗口内发送文字消息。
- 首屏协议要求用户明确确认本人已满 18 周岁；当前服务端收据直接作为客户侧年龄声明，不再要求普通用户填写外部不透明引用。
- 陪伴者上架仍使用独立的商业资料与运营审核流程。
- v1.0 首发为文字陪伴；图片、语音消息、语音商品和实时语音不在本版本宣传范围内。

## 本次修复

- 修复正式工程只显示首页、后续页面因后端地址不可达而无法使用的问题处理链路。
- 移除普通用户公开互动所依赖的外部身份授权死门，同时保留 active 账号状态检查。
- 在账号状态写入并发时，于数据库事务内加锁并重读，避免社区帖子或消息越过最新账号状态。
- 在“发现”加入可点击的“陪伴广场”入口，确保公开社区从主导航可达。
- 移除“我的”页未开放的个性化推荐开关，保留可用的推荐记录管理能力。
- 修复 Web 开发模式错误启用 Worker 优先路径导致样式表返回异常的问题。
