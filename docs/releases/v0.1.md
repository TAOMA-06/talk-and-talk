# Talk&Talk v0.1 发布说明

日期：2026-09-01

状态：主代码已进入 `main`；外部发布尚未执行。

## 这版交付了什么

v0.1 将 Talk&Talk 的主要产品表面统一为“浅彩卡牌剧场”：低饱和多色卡片、叠加立体感、有限动效、克制卡通元素，以及明显减少的主界面文字。

本次主发行分支包括：

- 微信小程序 31 个页面与 18 个共享组件。
- 公开 Web 的 5 个入口页。
- NestJS `/api/v1`、Admin 与 Independent Review 的现有代码。
- v0.1 精简媒体包、截图画廊与本地验收记录。

## 体验变化

- 主界面减少解释性文案，只保留关键事实和下一步动作。
- 完整规则、协议、隐私、交易和安全说明回到法律页或运营界面。
- 小程序首页、发现、消息、订单、陪伴者工作台等核心场景使用浅彩叠卡。
- 动效只用于入场、反馈和场景切换；支持关闭动效后的稳定终态。
- 支付、退款、身份、危机、证据和审核继续保持严肃、明确、可追踪。

## 本地验证

已完成的本地门禁：

- 小程序 TypeScript、结构校验、UI4 审计与 894 次 API smoke。
- 微信开发者工具 31 页、3 宽度、2 主题，共 186 张截图矩阵。
- 首页与发现页有限动效采样，稳定帧一致。
- `motionOff=true` 终态复验。
- 公开 Web `npm run check`。
- Backend build、静态预检与生产工件检查。
- Admin / Independent Review 登录页 390px 与 1280px 本地视觉检查。
