## 架构扩展触发器

以下 200/10,000 等数字是待验证的初始容量假设，不是通用架构规律。每项必须绑定 owner、目标 SLO、压测环境、置信区间和复核日期，由实测结果覆盖。

- 候选供给超过约 200 或可售查询持续影响 SLO：评估物化可售索引。
- 经营漏斗超过在线 90 天/10,000 单限制：转异步聚合或数据仓库。
- 多实例下 worker 重复处理、锁竞争或通知积压显著：先量化，再拆队列/服务。
- 领域文件频繁冲突且团队并行受阻：按可售、交易、履约、财务读写边界拆分。
