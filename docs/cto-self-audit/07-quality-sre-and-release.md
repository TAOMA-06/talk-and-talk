## 建议 SLO 起点（需用真实基线批准）

| 服务 | 初始建议 | 停止/升级条件 |
|---|---|---|
| API 非资金读请求 | 月可用性 99.9%，P95 需按目标环境基线确定 | 连续错误预算消耗过快时暂停放量 |
| 下单/支付状态 | 不允许重复订单/重复扣款；未知结果必须可回补 | 任一未解释金额差异暂停新单 |
| 审核与安全队列 | 严重案件必须在真实排班 SLA 内被认领 | 无人在岗或 SLA 失守关闭高风险写入 |
| 数据恢复 | 参考仓库模板 RPO ≤ 15 分钟、RTO ≤ 1 小时 | 未演练前不得声称达标 |

这些数值只是待批准目标，不能在没有监控和恢复演练时标为 `PASS`。
