## 敏感性确认

- [ ] Git 中没有身份证、银行卡、合同原件、手机号、OpenID、聊天原文、支付签名、JWT、私钥、TOTP 或生产连接串。
- [ ] 截图和日志已按最小必要脱敏。
- [ ] 原始证据位于有访问控制、审计和保留策略的系统。
- [ ] 第三方或个人数据的保存具有明确用途和删除计划。
