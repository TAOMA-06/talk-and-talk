# 00｜审查方法与证据规则

## 1. 控制项字段

每个检查项至少记录：`Control ID`、`canonical_control`、`related_controls`、承诺/风险、目标 Gate、`required_evidence`、适用范围/功能开关、检查方法、证据 ID、实际证据等级、状态、责任人、复核人、截止时间、失效时间和残余风险。

`02`—`09` 是控制问题库，不直接计算 Gate。每个发布候选必须在 [总控制台账](./registers/control-register.md) 中实例化适用控制；总控制台账是该候选唯一可计算的判定源。相似控制只表达不同风险视角，必须指定一个 canonical control，其余通过 `related_controls` 关联，不能重复计为多个通过项。

## 2. 状态

| 状态 | 定义 |
|---|---|
| `PASS` | 当前范围、环境和候选 SHA 下有足够且未过期的证据 |
| `PARTIAL` | 控制已部分存在，但缺少覆盖、环境或运营证据 |
| `FAIL` | 已确认不满足控制要求 |
| `BLOCKED` | 依赖外部账号、资质、环境或责任人，当前无法完成 |
| `STALE` | 旧证据曾通过，但不再对应当前 SHA、配置、平台规则或时间窗口 |
| `UNKNOWN` | 尚未取得足够信息，且不能安全推断 |
| `N/A` | 有书面理由和复核人确认本范围不适用 |

“代码存在”“测试曾通过”“文档已写”不能自动换成 `PASS`。

## 3. 优先级

| 级别 | 判定 |
|---|---|
| P0 | 会造成违法/平台拒绝、资金错误、隐私泄露、重大安全事件、不可恢复数据损失或核心履约失败；阻断生产 |
| P1 | 会造成规模化失败、持续运营失控、重大体验/成本问题或审计不可追溯；进入受控试运营前应关闭或接受风险 |
| P2 | 改善效率、可维护性和长期扩展；按触发器排期，不阻断当前受控容量 |

P0 不允许 Conditional 或 waiver。P1 只有在没有 P0、不会削弱资金/安全/隐私/资质/恢复控制、记录批准人和自动到期触发器时，才可限时接受。

## 4. 证据等级

| 等级 | 证据 | 可支持的结论 |
|---|---|---|
| E0 | 口头描述、TODO、未执行清单 | 只能登记未知 |
| E1 | 需求、设计、政策、代码路径或配置模板 | 证明“已设计/可实现” |
| E2 | 固定 SHA 的自动测试、构建、静态检查、迁移和制品哈希 | 最多支持 G1 |
| E3 | 隔离 staging 的真实依赖、真机、故障注入和恢复记录 | 最多支持 G2 |
| E4 | 外部平台原始回执、生产只读证据、受控真钱、真实值班演练和多人签字 | 才可支持 G3 |

第三方自述只能证明其公开机制，不证明 Talk&Talk 已达到相同质量。

## 5. 时效

- 代码、构建、测试：候选 SHA 或依赖锁文件变化即失效。
- 部署配置、DNS/TLS、远端健康、告警链路：每次发布重验。
- 资质、平台类目、模板、商户权限：平台变更或证件到期时重验，至少季度复核。
- KYC、协议、税务、收款与培训：按各自有效期和人员状态重验。
- 恢复、事故、危机、客服和审核值班：至少季度演练；首次真实付费前必须完成一次。
- 市场对标、价格和平台政策：涉及决策时重新查一手来源。

## 6. 独立性

- 实现者不得独自批准自己的 P0 控制。
- 资金付款、退款例外、商业档案和高风险处罚保留职责分离。
- 申诉复核人不得是原处置人。
- 法务、财务、运营、安全和工程只签自己能负责的证据；CTO 汇总不替代岗位责任。

## 7. 放行算法

1. 先通过 G0：固定 SHA、依赖锁、构建环境、客户端、后端、域名、AppID、功能开关和明确排除面；工作树不干净或范围冲突时只能做调查，不能生成最终发布证据。
2. 运行 G1；失败项进入缺口台账，不通过“重跑直到绿”掩盖不稳定性。
3. 使用同一制品进入 G2；Mock 只验证分支，不计入真实微信、资金、通知或 TRTC 证据。
4. 收齐外部 P0 和 E4 证据后召开 G3 评审；记录接受的残余风险和回滚人。
5. G4 只看真实履约与单位经济；安全事故、金额差异和恢复失败拥有一票暂停权。

证据要求按控制项计算：G1 通常至少 E2，G2 至少 E3，G3 至少 E4；纯文档/决策类控制可在说明理由后指定不同等级，但不得用降低等级绕过真实资金、安全、隐私、资质或恢复证据。

## 8. 敏感证据处理

Git 内禁止保存身份证、银行卡、合同原件、手机号、OpenID、聊天原文、支付签名、JWT、私钥、TOTP 秘钥和生产连接串。这里只记录受控系统中的引用、采集时间、负责人、最小摘要和不可逆哈希。
