# 08｜合规与外部门禁

> 适用范围和平台要求会变化。以下是基于当前“成年人、纯线上、一对一 text-only 首发、公开轻量 UGC、付费预约、平台抽成与人工结算”的行动目录；语音只是仓库内延期能力，不在本次首发。本文不构成替代属地监管、微信平台或合资格顾问意见的法律结论。

## 1. 必须完成

| ID | 门禁 | 完成证据 | 无证据动作 |
|---|---|---|---|
| CG-01 | 经营主体与责任 | 实际经营主体、合同主体、客服/争议/隐私责任人与银行税务信息一致 | 不对外收费 |
| CG-02 | 小程序备案与企业认证 | 微信后台原始回执、主体和当前 AppID | 不提交正式发布 |
| CG-03 | 真实服务类目与隐私接口 | 按当前功能申请类目，保存平台要求、驳回/批准和隐私接口审核 | 不绕类目上线 |
| CG-04 | 域名/服务器备案 | 若使用中国大陆服务器和独立域名，保存 ICP 备案、接入和域名主体一致证据 | 不切大陆生产域名 |
| CG-05 | 微信支付 | AppID/商户绑定、JSAPI、退款、平台证书、回调、账单和消费者投诉权限 | 不收真钱 |
| CG-06 | 用户真实身份 | 信息发布、公开 UGC 和即时通讯前完成适用的真实身份认证；OpenID 单独不作为充分证据 | 不向未完成认证者开放相关服务 |
| CG-07 | 成年与陪伴者 KYC | 真实身份、成年、协议、税务、收款与双人复核引用 | 不上架、不接单、不结算 |
| CG-08 | 隐私与个人信息 | 最终隐私政策/协议、最小必要、敏感信息、第三方 SDK/处理者、数据权利和 PIA | 不处理正式用户数据 |
| CG-09 | 内容与安全运营 | 人工审核/申诉、危机/客服排班、地区资源、媒体删除和事故响应演练 | 公开写入失败关闭 |
| CG-10 | 财税与售后 | 佣金、收入确认、发票、税务、退款、迟到/爽约、投诉和结算责任签字 | 不放开付费流量 |
| CG-11 | 安全评估 | 当前小程序含公开信息分享/即时通讯，上线前完成规定要求的自评并按适用程序提交报告；归档回执、整改和复核 | 未完成前不发布相关服务，不把代码审核替代安全评估 |
| CG-12 | 算法推荐治理 | 个性化推荐规则、基本原理、关闭和删除标签可达；若被认定具有舆论属性或社会动员能力，完成算法备案、编号标注和安全评估 | 未确认前保持受控，必要时关闭个性化 |
| CG-13 | 生产工程 | TLS、独立 DB/Redis、密钥管理、告警、备份恢复、容量、回滚和值班 | 不切生产 |
| CG-14 | 敏感个人信息与受托处理 | 对身份、聊天、支付、申诉等数据完成最小必要、单独同意/PIA（适用时）、处理者协议、地域、删除与跨境判断 | 无批准前不扩大收集或向第三方/境外传输 |

## 2. 待平台或属地确认

| ID | 项 | 为什么不能先拍板 | 下一步 |
|---|---|---|---|
| CG-C01 | ICP 信息服务许可证 / EDI | 仅“收费”不足以判断；陌生人互动、UGC、付费陪伴、抽成结算和微信类目会影响结论 | 先按真实类目提交微信后台，带完整业务图向属地通信管理局取得书面口径 |
| CG-C02 | 公安联网备案 | 取决于实际互联网信息服务、服务器、属地和上线时点 | 用实际域名、主体和功能向属地公安网安确认并留存回执 |
| CG-C03 | 安全评估具体程序 | 信息分享、小程序等功能已进入适用情形；仍需确认实际报告对象、提交平台、属地和材料 | 先做完整自评，再向属地网信/公安确认程序，不用第三方套餐结论替代 |
| CG-C04 | 算法备案适用性 | 代码确有基于订单/行为标签的个性化排序；备案取决于是否属于具有舆论属性或社会动员能力的算法推荐服务 | 带真实推荐数据流向属地网信确认；保留关闭个性化的受控方案 |
| CG-C05 | 更强背景筛查 | 线上成年陪伴与线下上门风险不同，犯罪/征信等筛查还涉及合法性、必要性和公平性 | 由法务按服务地区、风险与申诉机制决定 |
| CG-C06 | 语音 TRTC 类目与录音 | 一对一语音、是否录音和公开直播的要求不同 | 文字先行；类目、回调、双真机和关房演练通过后再开语音 |
| CG-C07 | 网络安全等级保护适用性 | 取决于实际系统定级、部署、数据和属地要求，不能用小程序形态直接排除 | 用真实系统边界向属地公安网安/合资格机构确认定级、备案和测评路径 |
| CG-C08 | 陪伴者法律与结算关系 | 平台控制、定价、排班、抽成、结算和实际管理会影响用工、劳务、税务与消费者责任 | 由法务/财务按真实运营方式形成书面主体和责任图 |

## 3. 当前暂不作为首发门槛

| ID | 项 | 当前结论 | 重新评估触发器 |
|---|---|---|---|
| CG-N01 | 软件著作权 | 可并行办理，但通常不应替代或阻塞普通小程序首发硬门禁 | 平台/采购/融资或属地明确要求 |
| CG-N02 | 网络文化经营/网络表演 | 当前 text-only 暂未列为首发硬门槛，仍待平台、属地或合资格顾问按真实类目确认 | 增加语音、公开直播、网络表演、礼物打赏或相关节目，或平台提出要求 |
| CG-N03 | 网络视听/直播许可 | 当前不做公开直播或视频节目 | 增加直播、视频栏目、UGC 视频分发 |
| CG-N04 | 面向未成年人的产品模式 | 当前不主动面向未成年人，但仍必须执行消费者年龄边界、误入处置和动态核验，并绑定 CG-06、SP-05、TO-08 | 改为接纳未成年人时须独立立项，不是加一个开关 |
