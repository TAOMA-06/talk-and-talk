# Talk&Talk 小程序首发全场景连续录制脚本

本脚本与 `scenario-checklist.json` 一一对应。JSON 是状态与证据边界的权威清单；录制时只把完成项的 `expected_status` 从 `not_run` 更新为实际 `pass`、`fail` 或 `blocked`。不得预填通过。

## 录制范围

- 仅微信开发者工具中的小程序用户面和陪伴者用户面。
- 不录制 `/admin/`、`/review/`，不展示密码、TOTP、JWT、手机号或 session。
- 片头必须显示：`隔离本地演示 · 开发身份桥接 · 非微信真机/支付/生产验收`。
- 使用原生 5 Tab：`首页`、`发现`、`订单`、`消息`、`我的`。

## 录制前快照

| 快照 | 用途 |
|---|---|
| `A0` | 清空 storage，首次协议与法律页 |
| `U0` | 零历史普通用户：空状态、安全写操作 |
| `U1` | 历史普通用户：文字订单、会话、退款、客服、通知、发票 |
| `P1` | seed owner `13800000101` 对应 `c1`；录屏中不得展示号码 |
| `R1` | restricted/banned/tombstoned 隔离用户 |

`prisma:seed` 不会自动创建完整客户历史矩阵。录制前必须用独立 fixture 准备 `history_order_matrix`、`history_paid_text_conversation`、`resolved_support_ticket`、`support_update_notification`、`payment_dispute_state_matrix`、`restricted_consumer` 等键；fixture 只能指向 disposable DB/Redis。

## 连续录制顺序

### Chapter 01 · 首次进入与法律边界（S001–S006）

- [ ] `S001` 清 storage 冷启动，定格“在开始之前”和 text-only 声明。
- [ ] `S002` 不勾选，证明“同意并进入”禁用且无业务请求。
- [ ] `S003` 打开用户协议，拍当前版本、服务和退款边界。
- [ ] `S004` 打开隐私政策，拍本地规则/人工复核/不外发原文边界。
- [ ] `S005` 展示“仅进入账号权利与申诉”受限模式。
- [ ] `S006` 切换 U0，完成协议与 18+，进入首页。口播强调开发身份桥接。

### Chapter 02 · 首页与安全识别（S007–S011）

- [ ] `S007` 输入普通合成需求，拍“文字只在本页识别场景”。
- [ ] `S008` 选择场景，拍“查看适合这个场景的人”。
- [ ] `S009` 输入合成风险词，拍“安全优先”；确认没有自动举报或聊天。
- [ ] `S010` 打开紧急资源，拍 110/120、来源、核验日期和普通客服非紧急声明。
- [ ] `S011` 完成资源查看并返回，拍非紧急服务边界仍存在。

### Chapter 03 · 发现与陪伴者资料（S012–S017）

- [ ] `S012` 搜索并依次切换主题、语言、价格、可约时间、排序。
- [ ] `S013` 制造无结果，点击“清除条件，恢复推荐”。
- [ ] `S014` 打开 `c1`，拍文字商品、价格、北京时间和评价。
- [ ] `S015` 收藏后取消，拍两个按钮状态。
- [ ] `S016` 停止推荐后恢复，拍“仅影响推荐”的隐私说明。
- [ ] `S017` 从“我的”查看书签/最近浏览，再清空最近浏览。

### Chapter 04 · 身份与首发失败关闭（S018–S023）

- [ ] `S018` 在 `c1` 详情拍身份 authority 提示；禁用预约不产生订单。
- [ ] `S019` 切 U1 直达 payment 页，拍任何支付副作用前的不可用状态。
- [ ] `S020` 打开社区，拍浏览/举报可用、发布不可用。
- [ ] `S021` 打开历史会话，拍文字可读、发送框隐藏。
- [ ] `S022` 拍图片/语音入口不渲染及历史媒体边界。
- [ ] `S023` 切 P1 到服务管理，拍仅文字服务、历史 voice SKU 不可激活。

### Chapter 05 · 社区与安全举报（S024–S028）

- [ ] `S024` 切回 U0，浏览社区并切换两类内容。
- [ ] `S025` 点赞再取消。
- [ ] `S026` 对同一帖子举报两次，分别拍新回执和重复回执。
- [ ] `S027` 打开安全中心，执行“先离开当前互动”，拍不取消订单/不自动举报。
- [ ] `S028` 新建合成安全举报，拍案件编号、提交者摘要、进度和时限。

### Chapter 06 · 空状态、客服与通知（S029–S035）

- [ ] `S029` U0 订单空状态。
- [ ] `S030` U0 消息空状态及三个快捷入口。
- [ ] `S031` U0 通知空状态。
- [ ] `S032` U0 创建 general 客服案件，拍“待受理”详情。
- [ ] `S033` 切 U1，拍预置已解决案件和用户可读结果。
- [ ] `S034` 打开客服更新通知，验证跳到正确案件。
- [ ] `S035` 全部已读并返回消息页，拍未读归零但记录保留。

### Chapter 07 · 历史订单、履约与售后（S036–S045）

- [ ] `S036` U1 切换进行中/历史订单。
- [ ] `S037` 打开 pending 文字订单并取消。
- [ ] `S038` 打开 confirmed/unpaid 订单，拍支付隐藏、客服与取消保留。
- [ ] `S039` 打开 paid 订单，拍退款规则快照和时间线。
- [ ] `S040` 进入历史会话，拍只读文字、举报和客服入口。
- [ ] `S041` 在 aftercare 提交私密体验反馈。
- [ ] `S042` 发起本地退款，拍 pendingReview/processing，禁止出现“微信退款成功”。
- [ ] `S043` 打开履约争议并提交文字陈述，拍媒体入口关闭。
- [ ] `S044` 依次展示支付投诉正常、无记录、加载失败三态。
- [ ] `S045` 提交发票申请后撤回，拍 submitted → cancelled。

### Chapter 08 · 资料、账号安全与数据权利（S046–S052）

- [ ] `S046` 改合成显示名，性别设“暂不透露”，确认保存为未提供。
- [ ] `S047` 拍公开互动身份和个性化推荐均保持关闭。
- [ ] `S048` U1 下线预置的其他会话，当前会话保持。
- [ ] `S049` U0 新建访问/更正数据权利请求。
- [ ] `S050` 提交 opaque 成年核验引用，拍“不接收证件”和“提交不等于通过”。
- [ ] `S051` 申请注销后取消；不得进入最终擦除。
- [ ] `S052` 本章最后撤回协议并退出，拍历史记录不会删除的确认文案。

### Chapter 09 · 陪伴者用户面（S053–S059）

- [ ] `S053` 切 P1，从个人中心进入工作台并浏览总览。
- [ ] `S054` 新建/编辑/暂停/上架文字服务，确认无 voice 模式。
- [ ] `S055` 新增/编辑/暂停可约时段，拍上海时区和容量。
- [ ] `S056` 保存周期规则、休假例外、生成草稿、人工确认开放。
- [ ] `S057` 在“作为陪伴者”确认或拒绝预置文字订单；客户支付仍关闭。
- [ ] `S058` 查看入驻/KYC/协议/结算状态并提交文字资料审核；只使用 opaque 引用。
- [ ] `S059` 完成合成培训，浏览限制申诉、收益和安全；不执行真实付款或媒体证据。

### Chapter 10 · 错误、弱网与权限（S060–S065）

- [ ] `S060` DevTools 离线打开首页，拍错误而非空推荐。
- [ ] `S061` U1 离线打开订单，恢复网络后点击重试并恢复列表。
- [ ] `S062` 受控制造通知/客服摘要局部失败，拍 partial warning 与会话保留。
- [ ] `S063` 制造私人书签/最近浏览失败，拍未知状态不覆盖旧数据。
- [ ] `S064` 切 R1 restricted/banned，只展示最小法定自助入口。
- [ ] `S065` 打开 deletion-status，拍不泄露历史账号状态、日期和资料。

## 外部门禁：只录“被阻断”，不得执行（B001–B008）

| ID | 门禁 | 录制要求 |
|---|---|---|
| `B001` | 真实 wx.login / OpenID / session_key | 标记 `blocked_by_design`；开发身份桥接不可替代 |
| `B002` | 体验版上传、审核、真机 | 不操作；模拟器截图不可称真机证据 |
| `B003` | JSAPI 真支付、回调、退款、对账 | 不产生真实资金动作 |
| `B004` | 微信订阅消息实际送达 | 只展示站内通知和投递意图 |
| `B005` | TRTC / 麦克风 / 实时语音 | 正常导航不可进入 `/pages/voice/index` |
| `B006` | 图片/音频聊天与案件证据 | 入口保持隐藏 |
| `B007` | 真实 KYC、合同、税务、收款批准 | 只展示 opaque 引用和待审核状态 |
| `B008` | 生产 DNS/TLS、备份恢复、容量、值班、法务签字 | 不在 UI 录制中宣称通过 |

## 立即停止条件

- 页面要求真实 AppID、商户号、真实扣款、真实退款或微信订阅授权。
- 出现任何真实账号、手机号、OpenID、JWT、密码、TOTP 或支付签名。
- 本应失败关闭的订单、支付、社区发布、聊天、媒体或语音入口被打开。
- 错误状态被空列表覆盖，或本地状态被描述为微信/生产已通过。

## 收尾

1. 结束画面再次显示证据边界。
2. 保存截图/录像与每项实际状态；不要改写 `blocked_by_design`。
3. 清理 disposable DB/Redis 和临时 session；记录未清理项。
4. 最终标题只能写“隔离本地小程序用户场景演示”，不能写“微信真机验收”或“生产可发布”。
