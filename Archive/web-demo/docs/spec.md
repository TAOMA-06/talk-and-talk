# 前端演示版 MVP Demo 计划

## Summary
先做一个“移动端 H5 优先”的纯前端 demo，用浏览器即可演示核心业务闭环。后端、支付、实名、人脸、IM/语音都先用本地模拟数据和交互状态替代，但页面结构、数据模型和用户流程按未来可接后端的方式设计。

默认技术栈：Vite + React + TypeScript + Tailwind CSS + lucide-react。

## Key Changes / Implementation
- **演示主线**：女性用户视角完成“登录/认证提示 -> 选择沟通主题 -> 浏览陪伴者 -> 查看主页 -> 发起沟通/下单 -> 模拟聊天与语音状态 -> 完成订单 -> 评价”的闭环。
- **页面结构**：
  - 首页/发现：主题入口、推荐陪伴者、筛选栏、平台安全提示。
  - 陪伴者列表：按主题、价格、评分、在线状态筛选。
  - 陪伴者详情：头像、标签、认证状态、服务价格、评价、可约时间、发起沟通按钮。
  - 下单确认：主题、时长、价格、安全规平台感”，避免约会软件气质。
  - 使用清爽浅色底、深墨文字、少量珊瑚/青绿色状态色；卡片圆角控制在 8px 内。
  - 首屏直接进入可用产品界面，不做营销 landing page。
- **项目文件**：
  - 在当前目录创建前端项目。
  - 主要目录：`src/components`、`src/features`、`src/data`、`src/lib`、`src/styles`。
  - 不创建真实 API、不写后端、不接数据库。

## Test Plan
- 手动验收移动端宽度 390px、430px 和桌面浏览器居中预览。
- 检查完整闭环：发现 -> 详情 -> 下单 -> 沟通 -> 完成 -> 评价。
- 检查异常状态：未认证提示、支付处理中、举报弹窗、空筛选结果。
- 运行 `npm run build` 验证 TypeScript 和生产构建。
- 启动本地 dev server，提供可访问 URL。

## Assumptions
- 默认做移动端 H5 demo，而不是原生 iOS/Android。
- 默认优先演示女性用户下单闭环，陪伴者端只做轻量资料/接单展示。
- 默认所有后端能
