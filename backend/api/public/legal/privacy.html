Talk&Talk 隐私政策

版本 1.0 · 适用于 Talk&Talk 微信小程序 · 更新日期：2026 年 7 月 19 日

一、适用范围与同意

本政策说明 Talk&Talk 微信小程序如何处理个人信息。首次使用时，我们会在发起微信登录或业务 API 请求前展示本政策和《用户协议》；只有你主动勾选并同意后才进入服务。同意记录会先在本机保存政策版本、同意时间和文档地址；登录成功后，同一信息会关联当前平台用户 ID 并形成不可变的服务端审计凭证。打开协议正文时会访问承载本文档的 HTTPS 站点。

二、微信身份与账号

登录时，小程序调用微信登录能力取得一次性登录凭证，由服务端向微信校验并取得 OpenID 等账号标识，用于创建或识别你的 Talk&Talk 账号、防止冒用和维持登录状态。我们不在小程序客户端保存 AppSecret 或微信 session_key，也不会仅凭昵称自动合并其他渠道账号。

三、订单与微信支付

预约和支付时，我们处理服务对象、服务时间、订单金额、订单号、微信支付交易号、支付及退款状态，用于生成订单、调起微信支付、对账、退款和处理争议。支付由微信支付处理；银行卡号等支付账户敏感信息不会由本小程序直接收集。支付结果以微信支付服务端通知为准。

四、聊天、广场与安全审核

为交付陪伴服务、展示广场内容、支持举报和处理安全事件，我们保存你主动提交的聊天消息、广场内容、评价、举报内容以及相关发送时间和账号标识。请勿在聊天或广场中发送身份证号、银行卡号、精确住址、医疗记录等非必要敏感信息。

聊天和广场文本会先经过平台规则审核；在服务端配置了 AI 审核能力时，相关文本及必要的对话上下文可能发送给第三方 AI 内容审核服务（当前配置为 DeepSeek 时由其处理），用于识别骚扰、引流、诈骗、自伤风险和其他违规内容。AI 结果仅作为拦截、提醒或人工复核依据，不用于支付决策；发送给审核服务的内容不包含登录密钥、访问令牌或完整支付参数。

五、必要共享与委托处理

  • 微信：完成小程序身份校验、平台隐私授权与基础运行能力；
  • 微信支付：完成预支付、支付结果通知、对账与退款；
  • 第三方 AI 审核服务：仅在已配置并需要审核时处理聊天或广场文本；
  • 监管、司法或执法机关：在法律法规要求的范围内提供必要信息。

我们不会出售个人信息，也不会将聊天内容用于与本服务无关的广告画像。

六、保存与安全

信息仅在实现上述目的、处理争议及满足法律法规要求所需的期限内保存，超过期限后删除或匿名化。数据通过 HTTPS 传输，并采用访问控制、审计日志和敏感字段脱敏等措施；任何网络服务均无法保证绝对安全，如发生可能影响你权益的安全事件，我们会依法通知。

七、你的权利

你可在「我的」页面查询或更正昵称、性别等资料，申请注销账号，或撤回本政策同意并退出。你也可拒绝首次同意；此时不会发起登录或业务 API 请求，但无法使用需要账号、聊天、订单或支付的功能。微信平台隐私授权还可通过微信的小程序权限设置撤回；撤回不影响撤回前基于同意进行的处理。

八、未成年人

本服务面向年满 18 周岁的用户。未满 18 周岁请勿注册、下单或提交个人信息。

九、联系我们与政策更新

如需行使个人信息权利、举报安全问题或咨询本政策，请通过小程序内平台客服渠道联系运营方。政策发生实质变化时，我们会更新版本并重新取得明确同意；小程序主体及运营者信息以微信展示的认证主体信息为准。
